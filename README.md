## Тренировки по линейным моделям и основным библиотекам
`training_linear_models.ipynb` - собственная реализация линейных моделей с градиентным спуском и регуляризацией, метрик классификации и сравнение по скорости обучения
и качеству с моделями **ScikitLearn** (не сильно уступают по качеству, но обучаются дольше). Использование различных оптимизаторов: `GridSearchCV`, `Optuna` и др.
Тренировки по библиотекам содержат различные задачи по EDA, анализу качества моделей и практике основных методов.
